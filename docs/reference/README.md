# Reference

How devices and viewers talk to the worker. Read these to write your own client. [pi-webrtc](https://github.com/mazupo/pi-webrtc) and [@mazupo/client](https://github.com/mazupo/client-sdk-js) already do all of this.

- [Token API](token-api.md): get an access token with a public key.
- [Messages](messages.md): the socket messages, close codes and error codes.
- [Data channels](data-channels.md): send messages between a device and its viewers.
- [Voice](voice.md): viewers talk, and devices play their voices.
